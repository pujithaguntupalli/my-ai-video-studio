# My AI Video Studio v2.0

## What's New in v2.0
1. **AI-Illustrated Storyboard Engine (Default, Free, Zero-Key):** Generates real AI artwork matching your exact prompt and style (e.g. a girl walking under cherry blossom trees in Anime style) and animates each scene with Ken Burns camera pan/zoom and atmospheric particles.
2. **Cloud AI Video API Support (Fal.ai):** Open **Settings & API** in the sidebar and paste a Fal.ai API key to generate true neural text-to-video clips (Wan 2.1, MiniMax, Luma) directly from Vercel.
3. **One-Click Video Export:** Click **Combine & Render Video** to export a downloadable `.mp4` / `.webm` video file directly in your browser.

## Deploy to Vercel
1. Replace `frontend/src/App.jsx` in your GitHub repo (or upload this entire extracted folder).
2. In Vercel, keep **Root Directory** set to `frontend`.
3. Vercel will automatically redeploy your live app. Default PIN: `2026`.
